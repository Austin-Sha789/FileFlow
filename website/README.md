# FileFlow website

A small, standalone product page. Plain HTML and CSS; no build tools, analytics,
external fonts, or JavaScript are required. All public copy is in English.

## Preview locally

Open `index.html` in a browser, use VS Code Live Server, or run from this directory:

```sh
python -m http.server 8000
```

Visit http://localhost:8000. Downloads and project links lead to the existing
Austin-Sha789/FileFlow GitHub repository. The current download links are pinned
to the published v1.0.0 release; update them and the visible version together
when publishing a later release. Do not link to unreleased local changes.

## Publishing

This directory is ready for a static host. It has not been deployed. To use
GitHub Pages, publish this directory through a Pages workflow after enabling
Pages in repository settings. No workflow is added here, so pushing this page
does not publish a site or change desktop installers.

The logo is copied from the desktop app's original PNG asset.
