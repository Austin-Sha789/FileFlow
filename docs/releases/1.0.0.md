# FileFlow 1.0.0

FileFlow 首次公开安装包发布，提供 Windows x64、macOS Apple Silicon 和 macOS Intel 版本。安装包内置 Java 运行环境，无需另外安装 Java 或 Maven。

## 下载与安装
- Windows：下载 `FileFlow-1.0.0-windows-x64.msi`，运行安装向导。
- Apple Silicon（M 系列）：下载 `FileFlow-1.0.0-macos-arm64.dmg`，打开后将 FileFlow 拖入 Applications。
- Intel Mac：下载 `FileFlow-1.0.0-macos-x64.dmg`，打开后将 FileFlow 拖入 Applications。

这是未进行开发者身份签名的首版。Windows 可能显示未知发布者提示；macOS 安装包未经 Developer ID 签名和 Apple 公证，Gatekeeper 可能阻止首次打开。请按系统提供的验证和管理流程判断是否安装，不需要关闭全局安全保护。Mac 应用仅带运行必需的本地 ad-hoc 签名。

## 功能
- 文件扫描、分类、收藏、标签、重复文件和相似图片检查。
- 中英文切换、暗色桌面界面、Mac 原生窗口红绿灯。
- 静态图片和视频预览，以及手动检查更新、下载安装包。
- 普通扫描不再自动加入工作区；工作区条目通过“管理文件夹”保存。

## 数据与更新
收藏、标签和扫描记录保存在用户目录，升级不会写入安装目录：Windows `%LOCALAPPDATA%\FileFlow`，Mac `~/Library/Application Support/FileFlow`。
旧源码运行目录中若存在 `fileflow.db`，首次从该目录启动时会使用 SQLite 一致性复制迁移，保留原文件。直接从新安装的应用启动不会自动搜索旧仓库，可在退出程序后将旧库复制到上述用户目录（已有数据时先备份）。

附件包含 SHA-256 校验文件及目标平台的打包启动自检报告。Windows/两种 Mac 架构均在对应系统构建；自检覆盖内置运行环境、JavaFX 主窗口、资源版本与 SQLite，不等于完整人工验收。
