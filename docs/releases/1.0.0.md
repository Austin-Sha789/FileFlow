# FileFlow 1.0.0

The first public installer release of FileFlow, available for Windows x64, Mac Apple Silicon and Mac Intel. Each installer includes a Java runtime; Java and Maven are not required to use the installed app.

## Download and install

- **Windows:** download `FileFlow-1.0.0-windows-x64.msi` and run the installer.
- **Mac with Apple Silicon (M series):** open `FileFlow-1.0.0-macos-arm64.dmg` and drag FileFlow into Applications.
- **Intel Mac:** open `FileFlow-1.0.0-macos-x64.dmg` and drag FileFlow into Applications.

This release is not signed with a developer identity. Windows may show an unknown-publisher prompt. Mac packages are not Developer ID signed or notarised by Apple, so Gatekeeper may block first launch. Mac apps carry only an ad-hoc signature required to run. Use the verification and management options provided by the OS; global security protections do not need to be disabled.

## Features

- Folder scanning, file categories, favourites, tags, exact duplicates and similar-image review.
- English and Simplified Chinese interfaces, a dark desktop theme, and native Mac window controls.
- Static image/video previews and manual update checks with installer downloads.
- Workspace shortcuts saved through Manage Folders; ordinary scans no longer add entries automatically.

## Known issues

- [#1: MOV video thumbnails may not appear on macOS](https://github.com/Austin-Sha789/FileFlow/issues/1). Engine discovery and Quick Look fallback are implemented, but the reported issue remains unresolved. Some MOV files may still show a placeholder.
- Mac appearance, media codec coverage and system permissions need broader testing.

## Data and updates

Favourites, tags and scan history live in the user data directory: `%LOCALAPPDATA%/FileFlow` on Windows and `~/Library/Application Support/FileFlow` on Mac.

Launching from a legacy source directory containing `fileflow.db` can migrate a consistent copy while retaining the original. Installed apps do not search old repositories automatically. Exit the app and back up any existing data before manually copying an old database into the user data directory.

Release assets include SHA-256 checksum files and target-platform startup reports. All three packages are built on their target operating systems. Startup checks cover the bundled runtime, JavaFX main window, version resource and SQLite; they do not replace full manual installation and upgrade testing.
